# Calc 2600

A simple Android calculator with a dark, Samsung-inspired interface.

## Special result
Whenever a calculation evaluates to exactly **2600**, the display shows:

**حمید از ریشه خرابه**

All other calculations display their normal numeric result.

## Build
The GitHub Actions workflow builds a debug APK on every push to `main`, and also supports manual runs. Download the APK from the workflow run's Artifacts section.
